# Music Assets

Place your game's loopable background music files (.mp3) in this directory.

## Expected Files

- `MvG2023_Menu1.mp3` — Menu Theme Option 1
- `MvG2023_Menu2.mp3` — Menu Theme Option 2
- `MvG2023_Run.mp3` — Standard Run Gameplay Theme
- `MvG2023_BossFight.mp3` — Boss Encounter Theme

## Path Resolution

Any file placed here becomes accessible in the app under `/assets/music/your_filename.mp3`.
